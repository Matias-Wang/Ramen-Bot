# 日本拉麵知識庫：口味與流派 RAG 專用文件
## 一、 日本拉麵基本五大元素

日式拉麵的多元變化，皆由以下五個核心元素交織而成 ：

- 麵條（麺）：分為直麵、捲麵、粗麵與細麵 。麵條的彈性、嚼勁與吸湯能力，取決於小麥粉種類與「加水率」（加水率低的麵條內含水分少，更易吸附湯汁但泡久易軟爛） 。製麵時加入「鹼水」是拉麵與烏龍麵、蕎麥麵最大的不同，能賦予麵條獨特風味、彈性與淡黃色澤 。
- 湯底（スープ）：拉麵的靈魂基石 。熬製工法依火候分為文火慢燉、澄澈見底的「清湯」，以及大火催谷、使蛋白質和脂肪充分乳化成雪白濃稠的「白湯」 。原料主要分為：
  - 動物系：豚骨（豬骨）、雞骨（近年雞白湯大受歡迎）、牛骨等 。
  - 魚介系（海鮮）：鰹節（柴魚）、煮干（小魚乾）、鯖魚乾、昆布、貝類等 。
  - 蔬菜系：洋蔥、大蒜等時令鮮蔬 。
  - W高湯（雙高湯）：將動物系與魚介系高湯分開熬煮，上桌前以黃金比例融合，兼具骨湯濃厚與海鮮鮮香 。
- 調味醬汁（タレ）：負責賦予高湯主要調味與味覺靈魂，通常是各店家的獨門保密配方，主要分為醬油、鹽味、味噌 。
- 香味油（油）：漂浮於湯面鎖住熱度並增添香氣與厚度，常見高手包括雞油、豬背脂、大蒜黑麻油、煮干油等 。
- 配菜（具）：豐富口感與視覺，常見有叉燒肉、溏心蛋、筍乾、蔥花、海苔、木耳、豆芽菜等 。

## 二、 四大傳統口味分類
早期的拉麵主要是依據「調味醬汁（タレ）」與湯頭特徵來做基本歸類 ：

### 1. 醬油拉麵（醤油ラーメン）
- 特徵：日本拉麵的原型與開山祖師 ，以東京淺草的「來來軒」為早期代表（東京拉麵的基底） 。
- 風味與風味：通常以雞骨、豬骨或魚介高湯為底，加入醬油醬汁 。湯頭多呈現澄澈的茶褐色（琥珀色），口味清淡鮮甜（淡麗系），但依店家調配也有濃醇風味，變化度極高 。多搭配中細麵 。

### 2. 鹽味拉麵（塩ラーメン）
- 特徵：日本歷史上最早登場、在日販售的第一款拉麵口味，起源於北海道函館 。
- 風味與風味：外觀呈現清澈金黃色的湯頭 。以最純粹的食鹽為基礎調味，通常搭配雞骨、豬骨、昆布或海鮮清燉 。口味在所有拉麵當中最為清爽不油膩，極度考驗職人熬製高湯的功力 。多搭配細麵或中細麵 。

### 3. 味噌拉麵（味噌ラーメン）
- 特徵：發源於北海道札幌（由「味之三平」創業者大宮守人開發） ，是第一個將日本傳統味噌融入拉麵的流派 。
- 風味與風味：多以濃郁的豚骨或雞骨高湯為底，加入大量大豆香氣的味噌醬汁 。為了因應北國嚴寒氣候，湯頭表面常會覆蓋一層豬油膜以保持熱度，並加入蒜蓉、生薑、芝麻增添層次 。配料常伴隨大火快炒的豆芽菜、洋蔥與絞肉，分量十足，通常搭配有強勁咬勁的中粗（中太）黃色捲麵 。

### 4. 豚骨拉麵（豚骨ラーメン）
- 特徵：源自九州北部（福岡博多、久留米、長濱等地） 。其濃白湯頭源於一場「美麗的錯誤」（意外將豬骨高湯大火煮過頭，導致明膠質與脂肪完美乳化） 。
- 風味與風味：使用豬骨長時間高溫燉煮，湯頭呈現乳白色，口感滑順、油脂豐厚且膠質滿滿 。標準搭配低加水率的「極細直麵」 ，因細麵能快速吸附濃湯且極快煮熟（最早為了服務魚市場趕時間的勞動者） 。由於細麵易泡軟，因而延伸出麵量較少、吃到一半隨時加麵的「替玉（替え玉）」文化 。

## 三、 日本三大拉麵與特色地方拉麵
地方拉麵深刻反映了當地的氣候環境與工人群眾的飲食需求 。

### 1. 札幌拉麵（北海道）—— 三大拉麵之一
- 核心代名詞：濃厚味噌、中粗捲麵、油脂保溫 。
- 風味特色：以濃郁豚骨搭配重口味味噌，表面浮著厚厚豬油用以抵抗嚴寒 。配料常見玉米、奶油、大火炒過的豆芽菜與蔬菜 。

### 2. 喜多方拉麵（福島縣）—— 三大拉麵之一
- 核心代名詞：醬油風味、早餐拉麵、清爽天天吃不膩 。
- 風味特色：福島縣喜多方市人口雖少，拉麵店密度卻極高 。湯底以豬骨和小魚乾（煮干）熬煮，屬於淡麗清爽的醬油派系，輕盈無負擔，當地居民甚至會在早餐享用 。麵條使用特有的「扁平多加水熟成麵」（寬捲麵），口感Q彈富有嚼勁 。當地設有《老麵會》組織維持正統品質（台灣「美濃屋」擁有其官方認證） 。

### 3. 博多拉麵（福岡縣）—— 三大拉麵之一
- 核心代名詞：乳白豚骨、極細直麵、替玉（加麵）文化、客製化硬度 。
- 風味特色：濃醇厚實的乳白色豚骨鹽醬湯頭 。餐桌上提供極多調味料（如紅薑、白芝麻、高菜）供客人自由變換風味 。

### 4. 德島拉麵（四國德島縣）
- 核心代名詞：飯吃系/配菜拉麵、鹹甜茶系、生雞蛋、五花肉 。
- 風味特色：在當地常被當作「配菜」而非主食，因此通常會加點白飯配著吃（澱粉狂飆組合） 。主要分為黃系（雞骨）、白系（豚骨）與茶系（豚骨醬油） 。現今大眾熟知的德島拉麵多指茶系：湯頭鹹中帶甜，特色是用甜味醬汁滷煮的豬五花肉片取代叉燒，並在麵中央打上一顆生蛋黃，口味十分濃厚 。

### 5. 燕三条拉麵（新潟縣）
- 核心代名詞：工廠勞工熱量、濃厚背脂保溫、煮干醬油、極粗麵 。
- 風味特色：源於新潟面海寒冷，且當地工廠密集、勞動人口多，需要高熱量體力 。為了保溫與補充熱量，拉麵表面撒滿一層厚厚的豬背脂（塊狀豬背油） 。基底則是小魚乾（煮干）熬製的醬油高湯，用鮮鹹鮮美平衡油脂的滑順 。為防止麵條在熱湯中過快軟爛，使用極具咬勁的粗麵（太麵） 。

### 6. 熊本拉麵（九州熊本縣）
- 核心代名詞：大蒜香油（マー油）、溫和豚骨 。
- 風味特色：同樣是豚骨基底，但比博多拉麵更溫和、少了強烈的豬騷味（因湯頭當天用完不留隔夜） 。最大特徵是淋上了由大蒜慢火煸炒製成的「黑麻油（焦香蒜油）」與炸蒜片，讓整碗拉麵呈現獨特的黑白色澤與濃郁焦香 。

## 四、 近代名店六大流派
隨著拉麵戰國時代演進，許多名店因極具特色的開創性作法，自成一家派系 ：

### 1. 家系拉麵（橫濱家系）
- 起源與代表：1974年由吉村實於橫濱創立的「吉村家」，其弟子分店常以「〇〇家」命名 。
- 湯頭與麵體：結合九州豚骨與東京醬油，打造出極度濃郁的「濃厚豚骨醬油湯頭」，表面淋上金黃雞油，搭配口感Q彈的粗直麵 。
- 經典配菜：叉燒、菠菜、大片海苔 。
- 客製化特色：點餐時可高度客製化調整（麵的硬度、湯的鹹淡、雞油分量） 。桌上備有豆瓣醬、蒜泥等眾多調料 。
- 靈魂吃法：麵吃完後，務必點一碗白飯倒入殘留的濃厚湯汁中，讓米飯吸飽豚骨醬油與雞油精華一同入口 。

### 2. 二郎系拉麵
- 起源與代表：起源於東京港區三田的「拉麵二郎 三田本店」（創始人山田拓美） 。在拉麵界有「二郎不是拉麵，而是名為二郎的食物」之狂熱格言 。
- 湯頭與麵體：油脂含量與鹽分極高的濃厚豚骨醬油湯底，搭配分量驚人、口感扎實的低加水極粗（極太）捲麵 。
- 震撼特徵：主打「量多、油多、味濃」 。視覺上堆積如山的豆芽菜與高麗菜、厚實巨大的豬肉塊（叉燒），並融入大量的背脂塊與大蒜泥 。極受大體力消耗者及狂熱二郎迷（ジロリアン）崇拜 。

### 3. 青葉系拉麵
- 起源與代表：1996年由東京中野的「中華そば青葉」開創，象徵拉麵跨入新時代 。
- 核心技術：「W高湯（雙高湯）」的始祖與普及者 。
- 湯頭特徵：完美融合了鰹魚、煮干等海鮮熬出的清澈「魚介高湯」，以及豚骨、雞骨經長時間大火熬煮的乳化「動物系高湯」 。標榜「濃中帶清」，既有海味的鮮甜回甘，又有骨湯的濃厚層次，圓潤柔和且不油膩，極受女性青睞 。

### 4. 麵屋武藏系
- 起源與代表：1996年創立於東京新宿總店，以劍豪宮本武藏命名 。
- 核心技術：開創「二刀流」湯頭，將帶有蕎麥麵露風格的甘甜和風醬油魚介高湯，與厚重乳白的動物豚骨湯融合 。
- 風格特徵：極具華麗視覺衝擊與流行創新感 。配料極度豪邁（如超厚切炙燒叉燒、大塊角煮燉肉） ，並且非常擅長推出融入跨界元素的期間限定拉麵（如結合辣味、萬聖節黑蒜等），是拉麵潮流的創造者 。

### 5. 大勝軒系（沾麵始祖）
- 起源與代表：由「東池袋大勝軒」創始人、被尊稱為「拉麵之神」的山岸一雄所奠定 。
- 核心技術：日本「沾麵（つけ麺）」的開山始祖 。
- 風格特徵：將煮熟過冷水沖洗、極具小麥香氣與極強嚼勁的太麵（粗麵），與一碗極度濃郁、酸甜辣平衡恰到好處的熱沾汁分開盛裝 。食客夾麵沾湯食用，充分展現麵條本體口感與湯汁沾附的雙重美學 。

### 6. Ganko系（がんこ系）
- 起源與代表：由一条安雪創立的「一条流がんこラーメン總本家」 。
- 風格特徵：極端、固執、魔性派的代名詞 。店面通常漆黑神祕、沒有招牌，僅在營業時於門口掛上一根「牛骨」作為地下結社般的暗號 。
- 湯頭特徵：以牛骨、海鮮等熬製出濃度極高的湯底，最大的特徵是「極鹹、極香」 。入口時強烈的重鹽分會直接衝擊味蕾，隨後浮現深沉的旨味（Umami），搭配入口即化的柔嫩叉燒，雖然口味極端卻讓人魔性上癮 。

## 五、 RAG 檢索增強優化提示（LLM 閱讀補充）
- 當用戶詢問「飯吃系」、「配白飯」的拉麵時：檢索定位為【德島拉麵】或【家系拉麵】 。
- 當用戶詢問「加水率」、「低加水麵」的物理特性時：檢索定位為【博多拉麵】（低加水細麵易吸湯、口感偏硬但易軟爛，故需替玉） 。
- 當用戶詢問「黑色的湯頭」或「大蒜風味」時：檢索定位為【熊本拉麵（黑麻油）】或特色拉麵【富山黑拉麵（極濃醬油）】 。
- 當用戶詢問「雙高湯/W高湯/海陸混合」時：檢索定位為【雙高湯（Wスープ）】、流派指名【青葉系】或【麵屋武藏系】 。
